# 🔮 เต็นท์ไพ่ทาโร่ของแม่หมอ

เว็บดูดวงไพ่ทาโร่แบบเกม เข้าไปในเต็นท์ 3 มิติ มีแม่หมอสวมฮู้ดปิดหน้านั่งอยู่หลังโต๊ะ เปิดม่านเข้าไป เลือกหัวข้อ สับหรือตัดไพ่ เลือกไพ่ แล้วเปิดดูคำทำนาย

สร้างด้วย HTML, CSS และ JavaScript ล้วน ใช้ [Three.js](https://threejs.org/) (r128) สำหรับฉาก 3D ไม่ต้องติดตั้งหรือบิลด์อะไร

## สิ่งที่มี

- **ม่านเวที 3 มิติ** เปิดจากกลาง ผ้ารวบเป็นพัดที่มุมบนสองข้างแล้วดึงขึ้นหายไป
- **ฉากเต็นท์ 3 มิติ** ผ้าเต็นท์ลายแดงทอง โต๊ะ แม่หมอ ลูกแก้ว เทียน และฝุ่นประกายลอย กล้องเอียงตามเมาส์หรือการเอียงมือถือ
- **ไพ่ 78 ใบ** ชุดใหญ่ (Major Arcana) 22 ใบ และชุดเล็ก (Minor Arcana) 56 ใบ มีทั้งไพ่ปกติและไพ่กลับหัว
- **11 หัวข้อ** รายวัน, รายเดือน, ความรัก, การเรียน, การงาน, การเงิน, สุขภาพ, บริวาร, โชคลาภ, ภาพรวมชีวิต และ Aim Valo วันนี้
- **เลือกจำนวนไพ่ 1 ถึง 3 ใบ** ชื่อตำแหน่งไพ่เปลี่ยนตามหัวข้อ (เช่น รายวันเป็น เช้า/บ่าย/เย็น)
- **สับไพ่ ตัดไพ่ หรือวางไพ่เลย** มีอนิเมชันสับไพ่ และปุ่มย้อนกลับในแต่ละขั้นตอน
- **หน้าเลือกไพ่เต็มจอ** ขนาดไพ่ปรับให้พอดีกับพื้นที่หน้าจอ
- **หน้าเปิดไพ่และคำทำนาย** แยกเป็นหน้าเต็มจอ ไม่ยืดหน้าลงมา
- **หน้าความหมายไพ่ทั้ง 78 ใบ** กรองตามชุดได้ ดูความหมายไพ่ปกติ ไพ่กลับหัว และความหมายของ Aim Valo
- **ปรับตามอุปกรณ์** ใช้ได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์ ปุ่มความหมายไพ่ย้ายลงมุมขวาล่างบนมือถือ
- **สำรองอัตโนมัติ** ถ้าอุปกรณ์เปิด WebGL ไม่ได้ หรือโหลด Three.js ไม่สำเร็จ จะใช้ฉาก 2D และม่าน CSS แทน

## วิธีใช้

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลด Three.js และฟอนต์จาก CDN)

หรือเปิดเป็นเว็บผ่าน GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root

## โครงสร้างไฟล์

```
├── index.html      โครงหน้าเว็บ
├── style.css       สไตล์ อนิเมชัน และการปรับตามขนาดจอ
├── script.js       ตรรกะเกม ข้อมูลไพ่ 78 ใบ ความหมาย และคำทำนาย
├── tent3d.js       ฉากเต็นท์ 3 มิติ (Three.js)
├── curtain3d.js    ม่านเวที 3 มิติ (Three.js)
├── README.md
└── images/cards/   รูปไพ่ 00.webp ถึง 77.webp
```

ลำดับรูปไพ่: `00` ถึง `21` คือชุดใหญ่ (The Fool ถึง The World) ต่อด้วยชุดเล็กตามลำดับ ไม้เท้า (22 ถึง 35), ถ้วย (36 ถึง 49), ดาบ (50 ถึง 63), เหรียญ (64 ถึง 77) แต่ละชุดเรียงเอซ สอง ถึง สิบ เพจ อัศวิน ราชินี ราชา

## ปรับแต่ง

| อยากปรับ | ไปที่ |
|---|---|
| ขนาดไพ่ในเต็นท์ และไพ่ที่เปิดดู | `--cw` และ `--rw` ที่บรรทัดแรกของ `style.css` |
| ความเร็วและความพริ้วของม่าน | ตัวหาร `2.6` ในบรรทัด `er=cl(...)` และตัวคูณ `A`, `sn` ใน `curtain3d.js` |
| สีผ้าม่านและความสว่างของจีบ | `BASE` และ `sh` ใน `curtain3d.js` |
| ตำแหน่งกล้องของเต็นท์ | `base` และ `cam.position` ใน `tent3d.js` |
| เพิ่มหรือแก้หัวข้อ | `T` (ชื่อหัวข้อ) และ `V` (คำสรุป 3 แบบ: ดี, กลาง ๆ, ต้องระวัง) ใน `script.js` |
| แก้ความหมายไพ่ | อาร์เรย์ `C` (ชุดใหญ่) และ `MM` (ชุดเล็ก) ใน `script.js` |
