# เต็นท์ไพ่ทาโร่ของแม่หมอ

เว็บดูดวงไพ่ทาโร่แบบเกม ใช้ HTML, CSS และ JavaScript ล้วน ไม่ต้องติดตั้งอะไร

## วิธีใช้
เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือเปิดใช้งานผ่าน GitHub Pages
(Settings > Pages > Deploy from a branch > main / root)

## โครงสร้างไฟล์
- `index.html` โครงหน้าเว็บ
- `style.css` สไตล์และอนิเมชัน
- `script.js` ตรรกะเกม ข้อมูลไพ่ และคำทำนาย
- `images/cards/` ภาพไพ่ Major Arcana 22 ใบ (00.jpg = The Fool ... 21.jpg = The World)

## เครดิต
ภาพไพ่ Rider-Waite-Smith (1909) วาดโดย Pamela Colman Smith เป็นสาธารณสมบัติ
ไฟล์สแกนบูรณะโดย Steve P. (steve-p.org) รวบรวมใน github.com/mixvlad/TarotCards

ไพ่ทาโร่ใช้เพื่อความบันเทิงเท่านั้น
